# AQORA Firebase Social Platform

This project is a scalable premium social network prototype built with HTML5, CSS3, Vanilla JavaScript, and Firebase.

## Structure

- `index.html` — entry point
- `CSS/` — styling and design system
- `JavaScript/` — app core and modules
- `Firebase/` — Firebase configuration and initialization
- `Authentication/` — auth bindings and logic
- `Pages/` — page structure for SPA views
- `Components/` — reusable UI component patterns
- `PWA/` — progressive web app manifest and offline support

## Firebase Setup

1. Create a Firebase project.
2. Enable Authentication, Firestore, and Storage.
3. Add web app config to `Firebase/config.js`.
4. Deploy with Firebase Hosting.
