# AQORA

منصة تواصل اجتماعي متكاملة قابلة للتوسع، مصممة لتتحول إلى تطبيق حقيقي مع واجهات حديثة وخادم API متصل بقاعدة بيانات MongoDB.

## ابدأ بسرعة

1. افتح مجلد `c:/Users/Ouali/AQORA`
2. انسخ ملف البيئة:

```bash
copy .env.local.example .env.local
```

3. ثبّت الحزم:

```bash
npm install
```

4. شغّل التطبيق:

```bash
npm run dev
```

5. افتح المتصفح على العنوان:

`http://localhost:3000`

## عرض الموقع

إذا شغلّت الخادم المحلي بنجاح، الموقع يعمل الآن ويمكنك التصفح على:

`http://localhost:3000`

يمكنك تسجيل حساب جديد عبر `/register` ثم الدخول إلى `/feed` و `/explore` و `/chat` و `/reels` و `/settings`.

## المتطلبات

- Node.js 20+ 
- MongoDB Atlas أو URI محلي في `.env.local`

## بنية المشروع

- `app/` - صفحات التطبيق وواجهة المستخدم
- `app/api/` - API routes مع المصادقة وبيانات المنصة
- `components/` - مكونات واجهة مشتركة
- `lib/` - اتصال قاعدة البيانات و JWT
